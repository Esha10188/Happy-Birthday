MAANI SIR BIRTHDAY SURPRISE — SOFT ROSE, LAVENDER & PEARL
=========================================================

HOW TO OPEN
1. Extract this ZIP.
2. Open the "Maani-Sir-Birthday-Surprise" folder in VS Code.
3. Open index.html.
4. Right-click index.html and choose "Open with Live Server" (if you have the Live Server extension).

THEME
Soft pearl ivory + dusty rose + lavender + muted champagne gold.
The main highlighted name is "Maani Sir". The page includes "Respected Sir", the birthday date
"2 November", and says the surprise is from Esha.

ADD YOUR PHOTOS
Put photos inside assets/images/
Expected filenames:
  maani-sir-01.jpg
  maani-sir-02.jpg
  maani-sir-03.jpg
  maani-sir-04.jpg
  maani-sir-05.jpg

If your image files have different names/extensions, update the matching src="..." in index.html.
Add more photo cards by copying a <figure class="photo-card"> block in index.html.

ADD YOUR VIDEOS
Put MP4 videos inside assets/videos/
Expected filenames:
  maani-sir-video-01.mp4
  maani-sir-video-02.mp4
Update the matching <source src="..."> paths in index.html if your filenames differ.

ADD MUSIC
Put your music file inside assets/music/
Expected filename:
  birthday-music.mp3
Music does not autoplay. The visitor must press "Play Music".
If you use a different filename, update the audio src in index.html.

NOTES
- Empty folders contain small instructions so they remain in the ZIP.
- Google Fonts need internet access; fallback fonts work without it.
- Please only use photos and videos you have permission to share.
